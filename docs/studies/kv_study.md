# Motor Kv as a design variable: study

Generated by `studies/kv_study.py report` from `outputs/kv/*.json` (not in git; a compact copy is in `docs/studies/kv_study_results.json`). Plan: `docs/KV_PLAN.md`. Model: `docs/modules/propulsion.md` (motor rewind). Single 10x7E 4S, the config's placeholder motor as the reference motor (Kv_ref 900 rpm/V, Rm_ref 0.05 ohm, I0_ref 1 A, 0.15 kg), Kv bounds 500-1500 rpm/V: **all PLACEHOLDERS** (OPEN_QUESTIONS Q7, Q34). Objective: the placeholder 3-lap time.

## Summary

- With Kv free the optimiser picks **Kv = 952 rpm/V**, set by **rpm_margin = 0 (active)**, and the 3-lap time drops from 79.728 s (Kv fixed at 900) to 78.520 s (-1.207 s).
- Current-limit sweep: I_max 40 A: Kv 952, set by rpm_margin = 0 (active); I_max 50 A: Kv 952, set by rpm_margin = 0 (active); I_max 60 A: Kv 952, set by rpm_margin = 0 (active); I_max 70 A: Kv 952, set by rpm_margin = 0 (active).
- Robust (μ + σ, Kv a DV, Kv_factor / Rm_ref uncertain): Kv = 953 rpm/V, μ = 78.830 s, σ = 0.642 s (UDR; fixed-Kv robust: 80.072 / 0.692 s). Kv rides the nominal rpm limit, which is not a robust constraint, so it is exceeded in 50 % of the Monte Carlo samples (§4, Q33).

## 1. Model checks

Hand check: static current, static thrust and rpm with the rewound Rm and I0 match an independent root solve at Kv = 700 and 1200 to 1e-9 (`tests/test_propulsion.py`). Kv = Kv_ref reproduces the fixed motor exactly, and the fixed-Kv configs reproduce the pre-Kv reference bit for bit (`tests/test_kv_dv.py`, `tests/test_rdo.py`).

Coupled analysis at the Kv bounds (other DVs fixed):

| Point | Kv (rpm/V) | MDA | 3-lap time (s) | level speed v (m/s) | I_static (A) | rpm_margin (rpm) |
|---|---:|---|---:|---:|---:|---:|
| start | 500 | converged | 126.97 | 18.21 | 7.3 | 5814 |
| start | 900 | converged | 83.22 | 35.67 | 33.1 | 827 |
| start | 1500 | **not converged** | - | - | - | - |
| fixed-Kv optimum | 500 | converged | 161.62 | 18.43 | 7.3 | 5761 |
| fixed-Kv optimum | 900 | converged | 79.73 | 38.37 | 33.1 | 622 |
| fixed-Kv optimum | 1500 | **not converged** | - | - | - | - |

At Kv = 1500 the MDA does not converge: the full-throttle level speed passes `v_top` = 50 m/s, the top of the T(v) fit range and the upper bound of the speed balance (at the fixed-Kv optimum the limit is near Kv ≈ 1205, from a bisection). The optimum (§2) is far below it, but an SLSQP line search that steps there stops the run as MDA non-convergence (OpenMDAO's SLSQP driver re-raises the analysis error). The bound is a placeholder (Q34); raising `v_top` or lowering the upper Kv bound would remove the failing region. Neither is done here.

**Reading.** Kv rides the rpm limit: `rpm_margin` = 0 at Kv = 952, while the static current (38.1 A) is well under I_max = 60 A. The rpm limit is 0.85 × APC's 150000/D[in] at the top (full-throttle level) speed: a higher Kv spins the prop faster at the top speed than that limit allows. The faster motor raises the level speed (38.37 → 40.43 m/s) and the battery grows to keep the 3-lap energy (0.886 → 1.000 Ah). The static-margin upper bound is no longer active.

## 3. Dependence on the current limit

Kv a DV, single 10x7E 4S, from the config start point; only I_max changes.

| I_max (A) | optimal Kv (rpm/V) | 3-lap time (s) | I_static (A) | I_margin (A) | rpm_margin (rpm) | Kv set by | converged / its |
|---:|---:|---:|---:|---:|---:|---|---|
| 40 | 952.0 | 78.520 | 38.1 | 1.86 | 0.0 | rpm_margin = 0 (active) | True / 40 |
| 50 | 952.0 | 78.520 | 38.1 | 11.86 | 0.0 | rpm_margin = 0 (active) | True / 40 |
| 60 | 952.0 | 78.520 | 38.1 | 21.86 | 0.0 | rpm_margin = 0 (active) | True / 40 |
| 70 | 952.0 | 78.520 | 38.1 | 31.86 | 0.0 | rpm_margin = 0 (active) | True / 40 |

**Reading.** The current limit never sets Kv in this range; at I_max = 40, 50, 60, 70 A the rpm limit does, and the optimum does not move with I_max. The expectation in the brief, that the optimum sits at I_static = I_max, does not hold for this prop and cell count: the rpm limit binds first, at a static current of 38.1 A, so I_max would only set Kv below that. The optimal Kv is set by the APC rpm limit (and its 0.85 factor, `propulsion.rpm_fraction`), not by the I_max placeholder; both are placeholders for a real motor/ESC (Q7).

## 4. Robust design with Kv a design variable

`configs/full_mdo_rdo.yaml`: UDR over Kv_factor, Rm_ref, m_avionics, m_motor, eta_h, lap.thrust_factor, m_pay (N = 15), minimise μ + 1σ, β = 2, as in docs/studies/rdo_study.md but with Kv a DV (Kv_factor and Rm_ref replace Kv and Rm). Compared with the fixed-Kv robust optimum of that study (UDR estimates for both).

| Quantity | fixed Kv (rdo_study) | Kv a DV |
|---|---:|---:|
| μ (s) | 80.072 | 78.830 |
| σ (s) | 0.692 | 0.642 |
| μ + kσ (s) | 80.765 | 79.472 |
| Kv (rpm/V) | 900 (fixed) | 952.7 |
| capacity (Ah) | 1.016 | 1.166 |
| SLSQP iterations | 41 | 40 |
| wall time (min) | 24.8 | 19.6 |
| converged | True | True |

At the reference node (all parameters at their means): rpm_margin = 0.0 rpm, I_margin = 21.8 A.

Monte Carlo over all 15 parameters (1024 Sobol' points, seed 0; 0 MDA failures): μ = 78.889 s, σ = 0.753 s.

| P(violated) | fixed Kv (rdo_study) | Kv a DV |
|---|---:|---:|
| energy_margin | 1.6 % | 1.4 % |
| rpm_margin | 0.1 % | 49.6 % |
| SM | 3.7 % | 3.6 % |

**Reading.** Kv again rides `rpm_margin`, which is not a robust constraint (it is enforced at the reference node only, OPEN_QUESTIONS Q33). With the winding tolerance (Kv_factor ±5 %) moving the rotor speed, the rpm limit is exceeded in 50 % of the samples. Adding `rpm_margin` to `robust.robust_constraints` would bound it; not done here, so the settings stay those of the RDO study.

## Caveats

- The reference motor, the Kv bounds, I_max and the rpm fraction are placeholders (Q7, Q34); with real motor data the binding limit can change.
- The rewind scaling assumes the same frame and copper fill (docs/modules/propulsion.md; citation needed).
- Kv is continuous; `api.reanalyse_with_motor` re-analyses a design with a catalogue motor.
